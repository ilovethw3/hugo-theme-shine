{{- $value := .value | default "•" -}} {{- $isImage := or (hasPrefix $value "/") (hasPrefix $value "http://") (hasPrefix $value "https://") -}} {{- $icon := lower $value -}} {{- if $isImage -}} {{- else if or (eq $icon "location") (eq $icon "address") (eq $icon "pin") -}} {{- else if eq $icon "phone" -}} {{- else if or (eq $icon "mail") (eq $icon "email") -}} {{- else if or (eq $icon "clock") (eq $icon "hours") (eq $icon "time") -}} {{- else -}} {{ $value }} {{- end -}}
